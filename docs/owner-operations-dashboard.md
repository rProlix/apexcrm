# Owner operations dashboard

The owner-only image operations page is available at `/owner/operations`.

It summarizes:

- original and derivative storage footprint
- images processed today
- duplicate reuse rate
- AI cache hit rate
- estimated AI spend and avoided cost
- active and failed queue counts
- operational alerts

This page is for platform owners. Tenants should see product-level status and business data, but not infrastructure internals or provider-specific implementation details.
